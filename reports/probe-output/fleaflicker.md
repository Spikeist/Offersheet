## Decisions

- Fleaflicker test league: FLEAFLICKER_LEAGUE_ID is blank, so the probe uses a pinned public 2026 league: 12 teams in 3 division(s), keeper (maxKeepers 25 of a 40-player active roster), IDP + taxi + IR + punter slots, 3 week(s) played, with traded future picks. - The scoring-oracle preview also runs on a second pinned public league with more conventional offensive scoring (0.5 per reception, 6-pt pass TD), because the main test league scores targets instead of receptions and has 27 rules the Sleeper keys can't express exactly.
- Canonical ids for Fleaflicker players: request rosters/listings with external_id_type=SPORTRADAR and match Sleeper's players DB sportradar_id (497/497 rostered players carry one), instead of the DynastyProcess fleaflicker_id (520 usable rows, 7 rostered players found). D/ST maps by NFL team code.
- Fleaflicker JSON is read with camelCase keys (live API) and proto3 defaults: missing number = 0, missing boolean = false, missing enum = its first value (e.g. BN slot group → BENCH, transaction type → TRANSACTION_ADD), except league.hasPlayoffs. A scoring rule's bounds come from rangeType, because a bound of 0 is omitted.
- Position mapping: CB/S → DB, EDR/IL (and DE/DT) → DL, LB → LB, D/ST → DEF; P (punter) has no model position and is reported as unmapped; a dual 'WR/CB' player uses its first position (also for the FantasyCalc match rate).
- League type is inferred from maxKeepers vs the active roster size (0 → redraft, ≥ roster → dynasty, else keeper): this league → keeper. Trade review: numVetoesRequired > 0 → league_vote; a review period without vetoes → commissioner.
- Scoring conversion: a rule's positions come from applyTo (applyToAll only marks "every position this league allows"). Definition adjustments (recFdIncludesRecTd, specialTeamsPlays, punterOnlyZeroTier) are switchable, and the oracle reports what each one fixes and breaks.
- Privacy: strangers' public leagues are described only generically in committed text; the rules-page "Lifetime" line is reduced to the keeper count; division ids are replaced (500000N); identities of leagues that are screened or read but never sanitized go to the git-ignored watch list for check:leaks.
